## What is NOT collected
- No name, birthdate, or other child-identifying field is ever prompted for (device name is the
  only child-editable text field, and it's a device label, not a person's name — though it
  *could* be repurposed by a user to contain a name; see `FAMILIES_AND_CHILD_SAFETY.md`).
- No location data.
- No contacts, SMS, call logs, or phonebook access — no such permission is declared.
- No browsing history or in-app-message content (nothing is read from screen content, per
  `ACCESSIBILITY_SERVICE_COMPLIANCE.md`).
- No IMEI/IMSI/SIM serial/MAC/BSSID/SSID/build-serial collection — no code path reads any of
  these identifiers anywhere in the app.

## Third-party processors
Only Google/Firebase (Auth, Firestore, Crashlytics) processes any of this data. No other
third-party SDK is integrated.
